# Vector Database Learning Project

A hands-on project to learn vector databases and semantic search.

## What this does
Stores text data and searches it by meaning, not by exact words.
Built using Python and ChromaDB.

## Tech used
- Python
- ChromaDB
- Semantic search / embeddings

## How to run
pip install chromadb
python basics.py

## What I learned
- What embeddings are
- How vector databases work
- How to search by meaning instead of exact keywords
